# IELTS Business Vocabulary Toolkit

An interactive front-end vocabulary learning web app built with HTML, CSS, and vanilla JavaScript.

## Overview

This project helps learners practice IELTS and business-related vocabulary through different interactive activities. It is a browser-based study tool designed to make vocabulary review more active and engaging.

## Features

- Brainstorming activity for vocabulary recall
- Interactive flashcards with multiple-choice answers
- Fill-in-the-gap practice with instant feedback
- Dynamic rendering with JavaScript
- User-friendly visual feedback for correct and incorrect answers

## Built With

- HTML
- CSS
- Vanilla JavaScript

## Project Structure

- `index.html` — main page structure
- `style.css` — styling and visual feedback
- `script.js` — app logic and interactivity

## Current Vocabulary Activities

### 1. Brainstorming
Users type vocabulary they remember, and the app checks their answers against the target terms.

### 2. Flashcards
Users review vocabulary through multiple-choice flashcards with feedback on correct and incorrect answers.

### 3. Fill-in-the-Gap
Users complete IELTS/business vocabulary sentences and receive instant answer feedback.
